## 🇬🇧 English

### 📌 About the Project
**Habit Tracker** is a modern and intuitive application designed to help users build positive habits, maintain daily consistency, and track their long-term progress. With a clean user interface and smooth user experience, this app allows users to create custom habits, keep track of daily streaks, and analyze their productivity over time.

### ✨ Key Features
- **Habit Management**: Easily create, edit, and delete daily or custom habits.
- **Streak & Consistency Tracking**: Keep track of current and longest streaks to stay motivated.
- **Interactive Calendar & Dashboard**: Visual representations (monthly/weekly views) of your progress.
- **Categorization**: Group habits by categories (e.g., Fitness, Learning, Health, Productivity).
- **Dark / Light Theme**: Clean UI with customizable viewing modes.
- **Responsive & Lightweight**: Fast performance and adaptable UI across different device screens.

### 🛠️ Tech Stack
- **Frontend / Mobile**: React / React Native *or* JavaScript / HTML / CSS
- **State Management**: Context API / Redux / Local Storage
- **Icons & UI**: Lucide Icons / Material UI / Tailwind CSS
- **Version Control**: Git & GitHub

### 📁 Project Structure
```text
habit-tracker/
├── assets/            # Static assets (images, icons, fonts)
├── src/               # Source files
│   ├── components/    # Reusable UI components (HabitCard, Navbar, etc.)
│   ├── context/       # State management and context providers
│   ├── pages/         # Screen/Page views (Dashboard, Stats, Settings)
│   ├── styles/        # CSS / Styling files
│   └── utils/         # Helper functions and local storage handlers
├── .gitignore         # Ignored files for Git
├── package.json       # Project metadata and dependencies
└── README.md          # Project documentation
```

### 🚀 Getting Started

#### Prerequisites
Make sure you have Node.js and npm/yarn installed on your machine.
- [Node.js](https://nodejs.org/) (v16.x or higher)
- `npm` or `yarn`

#### Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com/amirhosseindstr/habit-tracker.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd habit-tracker
   ```

3. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```

4. **Run the application:**
   ```bash
   npm start
   # or
   yarn start
   ```

## 🇮🇷 فارسی

### 📌 درباره پروژه
پروژه **Habit Tracker (ردیاب عادت‌ها)** یک اپلیکیشن مدرن و کاربردی است که برای کمک به افراد در ایجاد عادت‌های مثبت، حفظ تداوم روزانه و بررسی پیشرفت در طول زمان طراحی شده است. این برنامه با رابط کاربری ساده و جذاب به کاربران اجازه می‌دهد عادت‌های دلخواه خود را تعریف کنند، زنجیره موفقیت (Streak) خود را حفظ کنند و آمار عملکرد خود را مشاهده نمایند.

### ✨ ویژگی‌های کلیدی
- **مدیریت عادت‌ها**: قابلیت افزودن، ویرایش و حذف آسان عادت‌های روزانه و دوره‌ای.
- **پیگیری زنجیره تداوم (Streak)**: محاسبه و نمایش تعداد روزهای متوالی انجام عادت جهت افزایش انگیزه.
- **تقویم و داشبورد تعاملی**: نمایش بصری وضعیت انجام عادت‌ها به صورت هفتگی و ماهانه.
- **دسته‌بندی عادت‌ها**: امکان گروه‌بندی برنامه‌ها (مانند ورزشی، آموزشی، سلامتی و کاری).
- **حالت تاریک و روشن (Dark/Light Mode)**: طراحی پویا و متناسب با سلیقه کاربر.
- **پاسخگو و سبک (Responsive)**: اجرا و نمایش بهینه روی انواع نمایشگرها.

### 🛠️ تکنولوژی‌های استفاده‌شده
- **فرانت‌اند / موبایل**: React / React Native یا JavaScript / HTML / CSS
- **مدیریت وضعیت (State Management)**: Context API / Redux / Local Storage
- **طراحی و استایلینگ**: Tailwind CSS / CSS Modules / Material UI
- **کنترل نسخه**: Git & GitHub

### 📁 ساختار پروژه
